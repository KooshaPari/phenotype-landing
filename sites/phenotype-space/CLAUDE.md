# phenotype-space

Vue 3 + Vite SPA — one of the `phenotype-landing` sub-packages.

Sibling sites (`agileplus-landing`, `byteport-landing`, ...) are Astro; this
one is intentionally Vue to keep the keyboard 3D viewer and route-level
client state simple.

## Commands

```bash
npm install
npm run dev
npm run build
```
